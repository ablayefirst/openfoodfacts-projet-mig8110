Exemple de dossier d'archivage
==============================

Les anciennes extractions doivent être archivées ici par date :

- `data/archive/YYYYMMDD/` contient les anciennes versions horodatées.
- Garder un METADATA pour chaque fichier archivés.

Exemple de structure :

```
data/archive/20260211/
  openfoodfacts_products_20240210_v1.csv
  openfoodfacts_products_20240210_v1_METADATA.json
```

Ne pas écrire de données actives ici — l'archive est en lecture seule pour audit.
